# NCHU_IOT & Personal Dashboard

A modern personal dashboard and live real-time clock interface for **Hank Chang**.

## Features
- **Real-Time Live Precision Clock**: Shows hours, minutes, seconds, optional millisecond ticker, with 12h/24h toggle.
- **Dynamic Greetings**: Time-aware greeting based on local time.
- **Personalized Header**: Editable name with local storage persistence.
- **Date & Progress Engine**: Day progress meter, day of year, week number, and detected timezone.
- **Global Hubs**: Real-time clocks across Tokyo, London, New York, and San Francisco.
- **Daily Focus & Productivity Widget**: Interactive motivational focus modes.
- **Quick Launch Shortcuts**: Direct links to GitHub repo, developer portals, and search tools.
- **Dark & Light Mode**: Seamless glassmorphic theme transitions with animated ambient aurora glow.

## Live Demo / Local Run
Simply open `index.html` in any web browser, or serve locally:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
